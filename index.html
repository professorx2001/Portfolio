Apache Hudi Lakehouse Concurrency & Performance Optimization

Role: AWS Data Engineer

Re-engineered a high-latency Apache Hudi pipeline on Amazon S3 where sequential write streams with different primary key sequences caused severe write contention and 2.5-hour delays. Implemented physical table partitioning and Optimistic Concurrency Control (OCC) to enable safe parallel writes, reducing runtime to under 20 minutes.

OCC & Physical Partitioning: Implemented a table partitioning strategy paired with Optimistic Concurrency Control (OCC), leveraging DynamoDB as a distributed lock provider to safely manage concurrent commits.
Zero-Downtime Data Migration: Executed a historical data backfill to migrate existing records into the new partitioned Hudi table without data loss or corruption.
Parallel Pipeline Scheduling: Restructured daily AWS Glue jobs to execute concurrent parallel writes safely into the shared Hudi target table.
